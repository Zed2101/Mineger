Before you start

Java

Java 8, 17 or 21 depending on the Minecraft version. Mineger finds the installed runtimes and picks the right one.

SmartScreen

The installer isn't signed yet, so Windows may warn you on first run. Choose More info → Run anyway.

CurseForge key

Modrinth and FTB work out of the box. CurseForge needs your own free API key, pasted under Settings → CurseForge key.

Upgrading

Install over the previous version: servers and settings are kept.
